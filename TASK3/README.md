# TASK3 策略首秀：用均线交叉反应市场趋势变化

作者：张哲铭 | 北京大学 AI 量化工作坊

## 任务简介

实现经典的**双均线（Dual Moving Average）交叉策略**，用金叉/死叉信号捕捉趋势变化，
并以最大回撤（MDD）、夏普比率、累计回报、超额收益、胜率、盈亏比等指标全面评估。
先检索均线策略重要文献明确其有效标的，再对 **8 个标的 × 3 组周期共 24 组参数**做实证回测。

## 文件说明

| 文件 | 说明 |
|------|------|
| `prepare_data.py` | 将行情接口拉取的原始数据解析为标准 CSV |
| `strategy.py` | **回测引擎**：双均线、金叉死叉信号、仓位、成本、全套指标 |
| `run_backtest.py` | 多标的多周期回测主程序，出信号图/净值图/汇总图 |
| `extra_analysis.py` | 补充分析图：回撤对比、夏普热力图、收益-回撤散点 |

| `make_html3.py` | 生成网页版报告 |
| `backtest_results.csv` | 24 组回测指标汇总 |
| `张哲铭TASK3.pdf` / `.docx` | 作业文档（宋体五号、1.5 倍行距） |
| `index.html` | 网页版报告 |
| `data/` | 各标的日线 CSV |
| `figures/` | 全部可视化图形 |

## 回测标的

长江电力(600900)、腾讯控股(00700)、黄金ETF(518880)、红利低波50ETF(515450)、
纳指ETF(159941)、科创50ETF(588000)、沪深300ETF(510300)、中证500ETF(510500)。

## 核心结论

1. **黄金 ETF 是双均线策略的"主场"**：中线参数年化 15.0%、夏普 1.02、盈亏比 10.7，
   三组周期夏普全样本最高，与 Miffre & Rallis（2007）等文献"趋势性商品更有效"结论吻合。
2. **在整体向上的样本里，择时超额收益多为负**，印证自适应市场假说——高效率宽基指数上
   均线滞后导致高买低卖。
3. **策略真正价值在"控回撤"**：把腾讯回撤从 77% 压到 53%、科创50 从 60% 压到 46%，
   用少赚换取更平稳的持有体验。
4. **周期需匹配标的波动**：波动大选短周期抢反应，波动小选长周期滤噪音，没有万能参数。

## 运行

```bash
python prepare_data.py     # 数据准备（需先用行情接口拉取 data/raw_*.md）
python run_backtest.py     # 回测 + 主要图形
python extra_analysis.py   # 补充分析图
python make_doc3.py        # 生成 docx（转 pdf 需 Word）
python make_html3.py       # 生成 html
```

> 数据来源：腾讯自选股行情接口（前复权日线，2018–2026）。本项目仅为量化学习实践，不构成投资建议。
