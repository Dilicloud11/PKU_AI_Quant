## 任务概述
在 TASK5"用机器学习预测涨跌"的基础上，把模型输出的"上涨概率"转化为可执行、可回测的交易
策略：阐明 ML 交易策略的核心理念与优缺点、界定自变量因子与应变量、综述文献；设计
"双阈值 + 概率加权仓位 + 技术指标过滤 + 止损止盈"框架并网格搜索最优参数；对 8 个标的用
TASK5 中 Top3 算法产出样本外概率、构建策略并回测，给出四张核心图（何时交易/赚多少/
最大亏多少/仓位怎么变），系统对比不同算法，并完成附加题——多标的机器学习组合轮动。

## 策略框架
- **双阈值**：p≥买入阈值开/持仓、p≤卖出阈值清仓、之间维持原仓位（降换手、避不确定区）
- **概率加权仓位**：目标仓位 = clip((p−0.5)×2, 0, 1) × 最大仓位（确定性高则重仓）
- **技术过滤**：RSI>70 或 MA5≤MA20 或高波动分位时禁止新开仓
- **风控**：止损 / 止盈（基于持仓成本），单边成本万分之五
- **网格搜索**：买入阈值{0.55,0.60,0.65}×卖出阈值{0.45,0.50}×最大仓位{0.8,1.0}×止损{5%,8%}×止盈{15%,25%}

## 核心结论
1. **风险控制显著**：策略夏普普遍 >1（多在 1.2~2.4）、最大回撤压缩到个位数百分比甚至更低。
2. **单边牛市中普遍跑输买入持有**：择时为控回撤而降仓，必然在单边上涨中踏空（固有代价）。
3. **唯一显著跑赢的是腾讯**（测试段为下跌市）——印证 ML 择时价值主要在震荡下跌市，
   与 TASK3/TASK4"核心价值在控回撤"一脉相承。
4. **附加题组合轮动**同样未跑赢等权持有，因样本区间整体上行且宽基 ETF 高度相关——
   横截面选股更适合标的众多、分化明显的股票池。
