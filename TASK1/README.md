# PKU AI 量化工作坊 · TASK1

**量化交易初体验：从零搭建数据引擎**　｜　作者：张哲铭

## 任务内容
1. 量化交易相较传统手工交易的优势
2. 基本概念解释：K 线、基本面、技术面
3. 基于 Tushare 搭建数据引擎（研究标的：长江电力 600900.SH）
   - 获取过去一年每日交易数据
   - 绘制每日收盘价曲线图
   - 保存为 CSV 供后续任务复用
